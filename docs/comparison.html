AbyssplitvsLiveSplit

LiveSplit is the standard for a reason — hundreds of supported games and a huge autosplitter ecosystem. Abyssplit doesn't try to replace it everywhere. It's purpose-built for Abyssus, reading the game's own memory to do a handful of things a general-purpose, hotkey-driven timer structurally can't — for this game, today.

The headline differences

Three things live memory-reading unlocks

Cutscene-free timing

Forced cutscenes are true dead time — you can't skip them, can't play through them, and have zero control over their length. Abyssplit watches the game's own cutscene state live and strips that time out automatically, same as load removal.

No Abyssus autosplitter does this

Splits built from live data

LiveSplit runs off a split list authored before the run even starts. Abyssplit doesn't use a list at all — it watches your actual floor and room in real time and creates the split the instant you reach it. No missed splits, no fat-fingered hotkey.

No split list to author or maintain

Any number of loops

Abyssus lets you loop back for more depths before the final boss, so no two runs necessarily have the same number of floors. A fixed split list can't represent that ahead of time — floor 3 or floor 30, Abyssplit splits the same way.

Nothing to reconfigure between runs

What's next

Coming in future releases

Not built yet, not scheduled — but these go further than a general-purpose timer could follow even with a custom script, since they need to know things about your specific run that only reading the game live can tell you.

Roadmap

Auto-detect party size

Set Solo/Duo/Trio/Quad automatically from the actual number of players in the party — nothing to select before diving.

Roadmap

Per-weapon PBs for All Weapon%

All Weapon% already tracks like Any% — the missing piece is knowing which weapon a run started with, so PBs are kept separately per weapon instead of one shared pool.

Roadmap

Per-Deepwater-level tracking

PBs and run history kept separate per Deepwater level, the same way category and player count already are.

Roadmap

Ability, blessing & charm tracking

Auto-detect a No Blessings run without self-reporting it, plus new Stats breakdowns like average time by blessing.
